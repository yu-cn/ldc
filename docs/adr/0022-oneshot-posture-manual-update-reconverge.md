# 定位改一次性配置——更新与回归皆为显式手动行为

2026-11-21 主人定夺（WDC 侧 v1-program 纲领批准，方案 A：双仓保持 + 姿态对齐）。姊妹仓 [WDC 的 ADR-0009](https://github.com/yu-cn/wdc/blob/main/docs/adr/0009-oneshot-manual-update-reconverge.md) 同日改一次性配置定位，理由同源：持续收敛姿态把「机器随时与声明一致」当目标态，暴露面最大处恰是活机器上的反复触碰；一次性配置把暴露面收窄到显式时点。本仓镜像对齐（双仓各自独立项目、双边最优化不变——ADR-0007 委托契约与最小面不受影响）。

## 决策

- **默认姿态改一次性配置**：bootstrap 跑一次把机器带到声明状态，之后 LDC 休眠——机器日常归用户，漂移是合法状态而非异常。
- **更新与回归皆为显式手动行为**：更新=拉新声明后重跑（`ldc sync` / bootstrap）；回归=漂移后显式重跑、拉回**当前**声明状态。漂移积累越久单次回归覆盖面越大，`ldc plan` 干跑预演升格为回归前推荐步骤。
- **命令定性调整、机制原样**：`ldc sync` 从「日常一键同步」降为「手动更新/回归入口」（名字与行为不变，只改框架叙事）；`ldc` 快照 / verify / triage / audit 定性为按需诊断工具。幂等、渲染拷贝、收敛账本快速路径（ADR-0021）、flock 运行锁全部不动——**本 ADR 零行为变更**。
- **多机一致性承诺收缩**：一致性只在各机手动更新/回归时点对齐，「随时全绿」不再是目标态。

## 取舍

拒绝的替代：**收编 WDC 单仓**（主人 2026-11-21 明确定夺双仓保持——双边最优化与独立 CI/双发行版/双架构用户面不变）；**维持持续收敛叙事不改**（两仓产品叙事分裂——一边一次性一边持续收敛）；**删除 sync/verify/triage 机制**（手动更新/回归的工具箱，删了回归路径裸奔）。
