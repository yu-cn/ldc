# cli-ux-batch：CLI 体验优化批（2026-11-07 主人定夺「尽可能都做，充分优化」）

## 背景

主人问「wdc/ldc 有没有命令补全」引出双仓 CLI 全面体检。体检结论：无 Tab 补全、status 无
机器可读出口、`-h` 挂子命令语义不对（被静默吞）、`ldc log N` 无参数校验、sync 长操作完成
无通知；wdc 侧另有 fetch 无防护/缺 plan/子命令表手抄（wdc `.scratch/cli-ux-batch/` 同批）。
本仓做对齐补齐 + cli-parity 契约主作者位（dev-standard 同款统筹模式）。

## 票目

| # | 主题 | 性质 |
|---|------|------|
| 01 | `ldc status --json` 机器可读出口 + 退出码注册表进 help 总览 | 新能力 |
| 02 | 子命令 + `-h/--help` 落单命令详解（help 印刷重构为函数） | 一致性 |
| 03 | `ldc log N` 参数校验（正整数） | 小修 |
| 04 | sync 完成 BEL 通知 | 体验 |
| 05 | Tab 补全（bashrc 注册，子命令表单一来源解析） | 新能力 |
| 06 | `docs/cli-parity.md` 契约（主作者位本仓）+ guard 挂载 + validate 断言 | 防漂移 |
