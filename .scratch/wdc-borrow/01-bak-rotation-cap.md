# 工单01：dotfiles 备份轮转上限（3 份封顶，删最老必报告）

Status: in-progress

## 背景

install-dotfiles.sh render() 的备份轮转无限递增（`.bak` → `.bak.N` 无上限）——双向漂移频率虽低、长跑机器会攒档。wdc 工单44（2026-11-07 主人定夺）同语义同日落地：上限 3 份（`.bak` 本体 + 编号系列 ×2），本体永不清，编号系列超出删 mtime 最老并逐项报告——「机器侧内容绝不静默丢弃」以删除可见保持（非「不删」）。ADR-0015 是 LDC 主笔、双仓共用决策，定夺同源同效。

## 内容

- render() 备份分支成功后置 `bak_rotation_cap`：编号系列（`落点.bak.*`）>2 份时删 mtime 最老至 2，逐项 INFO 报告；清理未成不阻断（留存下次收敛重试）
- 头注释语义同步；ADR-0015 补记定夺；CHANGELOG [Unreleased] 记账
- 不涉 `.bashrc.bak` 整文件备份与 daemon.json 的 `.bak`（两者保最早原件、无编号系列，无攒档面）
